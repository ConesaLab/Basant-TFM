# Upload guide

1. Extract `Basant-TFM-GitHub-upload.zip` on your computer.
2. Open the private `ConesaLab/Basant-TFM` repository on GitHub.
3. Select **Add file → Upload files**.
4. Drag the contents of the extracted `Basant-TFM-GitHub-upload` folder into the upload area. Upload the `README.md`, `UPLOAD_GUIDE.md`, `scripts` folder and `supplementary` folder; do not upload only the ZIP archive.
5. Confirm that GitHub displays the complete folder structure before committing.
6. Enter the commit message: `Add thesis analysis scripts and supplementary materials`.
7. Select **Commit directly to the main branch** and choose **Commit changes**.
8. Keep the repository private until Ana Conesa confirms the files, visibility and reuse licence.

The repository already contains an R `.gitignore` file, so it does not need to be uploaded again.
