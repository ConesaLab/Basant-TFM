# Supplementary tables

## Preliminary and selected-gene analyses

- `selected_transcripts_sqanti3.tsv`: supplied SQANTI3, coding, ORF and predicted NMD annotations for the selected GAD2, INS and CHGA transcripts.
- `selected_genes_protein_sequences.xlsx`: supplied protein-sequence-level workbook used for the exploratory FSM, NIC and NNC pLDDT comparison across GAD2, INS and CHGA. The analysis uses the `Unique_For_Boxplot` worksheet.

## Main balanced dataset

- `selected_10002_proteins.tsv`: identifiers, genes, categories, protein lengths and similarity clusters for the selected balanced dataset.
- `master_table.tsv`: joined metadata and AlphaFold2 confidence metrics for 10,002 structures from 3,334 genes. Each gene contributes one FSM, one NIC and one NNC protein.

## PyMOL selection

- `top20_nic_fsm_manifest.tsv`: metadata for the 20 selected NIC models and their 20 gene-matched FSM models.
- `top20_pair_summary.tsv`: input and output filenames for the 20 PyMOL comparisons.
- `selected_six_pymol_pairs.tsv`: the three pairs with similar mean pLDDT scores and three pairs with large mean pLDDT differences selected for the six-panel thesis figure.

These tables combine upstream outputs supplied by the research team with downstream selection and summary information generated for the thesis. Their inclusion in a public repository should be confirmed by the research group before the repository visibility is changed from private to public.
