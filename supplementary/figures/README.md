# Supplementary figures

- `Figure_1_ORF_NMD_pLDDT.png`: descriptive comparison of five coding NIC isoforms grouped by predicted NMD status.
- `Figure_2_selected_genes_FSM_NIC_NNC_pLDDT.png`: exploratory comparison of FSM, NIC and NNC proteins associated with GAD2, INS and CHGA.
- `Figure_3_main_10002_structures_pLDDT.png`: main comparison of 10,002 protein structures from 3,334 matched genes.
- `Figure_4_selected_NIC_FSM_PyMOL_comparisons.png`: six-panel PyMOL figure containing three pairs with similar mean pLDDT scores and three pairs with large score differences.
- `pymol/selected_six/`: the six individual PyMOL images used in Figure 4.
- `pymol/top20/`: destination for the 20 images regenerated by the batch PyMOL script.

The current PyMOL images retain an evaluation-licence watermark for supervisor review. They should be re-exported with an academic/institutional licence or open-source PyMOL before public release or final publication; the watermark should not be removed by cropping.
